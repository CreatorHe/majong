# 国标无尽模式讨论稿

日期：2026-10-22。当前只实施日麻入口隐藏，公开玩法保留国标；以下无尽规则尚未实现，门槛数值尚未确定。

## 已确认的方向

- 基础六关通过后可以继续闯关，继续积累奇物与分数。
- 无尽阶段不断增加装备槽，获取更多**不同奇物**；整局始终只保留一件计分核心。
- 奇物通过随机刷新获得。首版沿用现有奇物，不增加资源、额外商店或局外永久养成。

## 候选流程

第六关通过时先记录“基础通关”，提供“完成旅程”和“继续无尽”。进入无尽保留累计分、奇物、成长值等跨关状态，沿用每关重新发牌与补充墨的现有规则。

选择继续后，槽位上限从四个增加为五个，领取一次随机三选一非核心奇物奖励，再进入第七关。此后每过一关再增加一个槽位、获得一次三选一奖励，可以跳过。槽位按通过关数增加，跳过奖励不会取消已增加的槽位。无尽不再有四槽或六槽的固定上限，但同名奇物不能重复装备，核心不能更换或额外获得。

基础六关的既有奖励规则保持；无尽奖励从路线适用、未持有的非核心奇物中随机抽取，单次选项互不重复，不额外保证兼容项，不增加付费刷新。这里的“随机刷新”指每次通关生成新奖励候选。

当前实际可用池为：大番、留牌各二十件非核心；刻子、成长各十九件非核心。补缺符只进入大番池，余音扇只进入留牌池；已停用奇物不重新加入。该数量来自当前配置，将来新增奇物时应同步更新。

剩余可选奇物不足三件时展示实际数量。全部持有后明确显示“当前路线奇物已收齐”，可以继续闯关，不展示空白奖励，不自动发重复品或升级。同一局最终能装备的不同奇物数量仍受现有内容池限制：含核心分别为二十一件或二十件。增加槽位不等于无限产生新奇物。

## 计分与失败

累计计分沿用：每关收益加入累计分；诈胡扣本关门槛的百分之十、向上取整，扣完仍达标则过关。门槛按关数预先确定，不根据玩家个人分数或上一手爆发追涨。第六关的倍率乘零点八仅用于第六关；后续暂不添加新的负面规则。

无尽失败或主动收官都保留基础通关记录。结算展示最高已通过关、结束关、最高单手分和累计分；当前累计分与曾达到的最高累计分须区分，避免诈胡扣分后混淆。

## 需要计算后再确定

门槛曲线尚未定稿。不能把原六关门槛直接外推后宣称已经平衡，也不把玩家已获得的大分数立刻折算成更高的专属门槛。

成长核心在持有复鸣铃时，一次合法三顺结算会把储存底分乘约二点五六五，四顺约三点五一一；它具有长期指数成长。其他路线收齐不同奇物后，牌型与多数触发倍率受到固定牌数和效果限制；但也能持有流云梳，按合法顺子持续线性积累底分，因此不能说它们存在绝对固定的单手上限。长期仍需比较指数成长与线性成长的差异。更多槽位还会使所有路线都能同时持有改牌和底分配件，现有六关的装备取舍将减少。需要重新计算各路线逐关生存率、得分分布、奇物收齐时间和溢出能支撑的关数，再决定门槛。

随机奖励需把未拿到关键配件、主动跳过和中途失败一并计入，不能只比较满配理论分。沿用一次结算生效一次、重触发不递归、不重复发放奖励的边界。

大分数可采用科学计数法展示；实际实现前须确定安全整数、增长溢出与存档边界，避免出现 `Infinity`、错误比较或静默截断。科学计数法仅改变显示，不能代替数值正确性处理。

无尽实现时还需覆盖继续按钮与奖励的重复领取保护、超过第六关的存档恢复、基础通关记录不被无尽失败覆盖。验收依赖真实浏览器试玩；自动化仅补这些会破坏核心流程的必要回归，不扩张正式脚本数量。
