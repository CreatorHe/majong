## 最新补算：5次全部限开局，以及大番专属补缺方向

用户继续讨论“5次是否过多、全部限开局会怎样”，随后提出让大番路线单独获得刷新／改牌手段，提高稀有牌型的可达性。这里按**每关5次、每次最多5张，均在首次出牌前使用**解释；只是对照方案，没有将新规则实装。

### 大番路线专属辅助：方向成立，参数待选

基础换牌首先保障四条路线都能正常组牌。稀有大牌的额外可控性通过大番核心和配套辅助获得，不普遍提高所有路线的刷新能力。现有数据说明这种分层有实际作用：同样5次开局，起手换色可把九莲从约0.35%提高到约1.35%。它也说明有改牌构筑的概率必须另测，不能用裸装概率去定关卡分数。

首版建议只做**一种专属补缺辅助**作为待算方案，不一次铺开多个特殊牌池：

- 需同时装备大番计分核心和该辅助，两者都占已有奇物槽。本关内锁定装备，消耗状态写入存档，不能借能力后换成另一计分核心。
- 每关一次补缺机会，在成型区尚未满14时使用；可选择“弃换最多3张候选牌”或“修改1张牌的点数±1／花色”。两项共用一次额度，不各给一次；改牌沿用墨消耗，不能凭空生成指定目标牌。次数、张数和费用都只是候选参数，尚未模拟。
- 这是大番路线对“开局后不能主动换／改牌”的明确例外。普通基础操作仍限开局，成型区整批替换仍关闭，不额外增加一种货币。
- 获得核心不等于已经拿到完整构筑。首关奖励可提供兼容辅助选项；后续期望值分别计算只有核心、已获辅助、额外改牌组合的情况。
- 当前纯正九莲仍未开放。仅凭最终14张九莲牌面不能额外认定纯正九莲；后续须明确和牌前13张九面听及和牌张时序，先记录为终局目标，不顺带加入双倍役满。

**暂不建议因九莲目标直接把5次开局再砍到3次。** 先用5次作为试玩对照，检查普通路线容错，再试算大番专属一次补缺的收益。四路线期望分与共同关卡门槛继续待这些边界确定后校准。本轮没有修改游戏规则或部署，也没有新增正式自动化测试。

结果、置信区间、方法和临时分析源码已保存到[计算JSON](../../research/2026-10-21-four-route-balance-calculations.json)的`openingOnlyFiveReview`；专属辅助草案位于`highFanRouteAssistanceProposal`。九莲最终引用独立混合种子的v3结果，早期种子调试结果不用于结论。

## 最新优先事项：换牌影响评估，次数待重新选择

用户最新希望先看禁用换牌的影响，再决定是否放开或提高次数；主要痛点是九莲宝灯过于容易。以下仅作方案比较，**没有实施禁换牌，也没有将新期望分数或关卡门槛定稿**。下节“起手一次”保留为上一版待执行草案；本文新增的5次对照也不视为用户已确认。

当前引擎仍为12候选、每关7次换牌、每次最多5张；第三关少2次，借东风多2次。九莲判定仍要求无杠、同花色、恰好14张，含1112345678999再加一张同色牌；未发现本次检查的两种模式在这一牌面条件上放宽。

七次减至五次，上述普通完成率下降14.56个百分点；九莲天然材料概率下降约79.2%。已有追清一色策略同样由36.66%降到11.52%。因此换牌次数确实有较强的大牌调节作用，但完全禁用会同时明显削弱普通和牌；不能据此推定最新起手一次规则的真实成型率。

### 九莲容易不仅是换牌次数的问题

现有引擎在成型区达到14张后、最终结算前仍允许改点数、改花色及万能牌；可看到后续牌再精准修补最终缺口。多4万缺5万可花1墨调整，多5筒缺5万可花1墨换色。这和只在起手未知后续牌时改牌的可控程度不同。

已有五次换牌的普通策略，只增加升降笔和4墨，完成率从73.52%提高到99.66%；这是改牌提供补救能力的证据，**不是九莲成功率**。尚未计算带改牌奇物、真实在线策略下的九莲率，不把素材概率、普通结构概率或传统麻将印象混为一谈。此前按三元、四风、国士素材对齐竞品的资源预算，亦不能证明九莲及改牌后玩法已经校准。

### 四路线与配套影响

- 高番：九莲／清一色的追缺张空间缩小；完全禁换还会削弱中档番型保底。应保留“没追到九莲也能完成较小和牌”的退路。
- 刻子重触发：找第三张、第四张更难；不能继续把四刻或多杠当常态。完全零重抽的26张全知天然牌池中，任意四刻＋雀头存在率也仅约0.131%；其并非实际玩家概率。
- 留牌：需要在和牌牌材与保留幺九之间分配12候选空间；取消组牌中的换牌后，不能再通过清洗候选提高末次留牌倍率。高留牌数量更难达到。
- 顺子成长：每关顺子触发数和合法结算数减少，既损失当关收益又损失后续复利，影响跨越多关。直接抬成长初值不能修复完全无法和牌的问题。
- 配套：借东风、千层塔、留白扇、第三关换牌惩罚均须重审；界面补救提示、操作阶段和存档亦受影响。累计分数与诈胡扣分后达标仍可过关的规则继续保留。

### 建议下一步对照（尚待用户选择）

优先讨论**5次、每次最多5张，组牌阶段仍可换牌**；若普通补救不足，再比较6次。该方案替代上一版“起手一次任意数量”，不是两套额度叠加。保留主动改牌仅限起手的限制，成型区替换继续关闭，分别降低精准补缺与额外纠错。第三关减2次和借东风加2次必须一起重审，不能悄然变成3次／7次的另一套难度。

这只是基于已有数据的首个对照点，尚未验证“5次＋起手改牌”的四路线真实收益，不据此宣布数值平衡。先确定供牌及操作时机，再计算期望得分与两模式累计目标；不通过抬高所有关卡分数去抵消九莲过易。

计算方法及精确分数已补入[计算JSON](../../research/2026-10-21-four-route-balance-calculations.json)的`redrawImpactReview`；本轮没有增加游戏自动化脚本。

## 最新决定：起手准备阶段与计划边界

**用户最新要求：以上先写入计划，不执行。** 当前游戏仍运行原有 V4 规则；下列抽牌、操作时机、四核心和获取节奏均未落地。最新规则替代“每关7次、每次最多5张重抽”的后续设计，也替代本轮中途讨论的“完全不能重抽”。

### 已确认的操作规则

- 每关开始阶段保留一次弃牌重抽，可选任意数量的当前候选牌；沿用12张候选时即一次选择1～12张。可以不使用，未用机会不带到组牌阶段或下一关。
- 开始组牌后不能主动弃牌重抽；成型区替换也停用，不能借替换后的补牌扩大牌库浏览量。
- 修改点数、修改花色、制作花色万能牌，也只在每关开始阶段进行。中途正常补到的牌不能再修改；已形成的牌不能再修改。
- 正常出牌仍是出几张补几张，其余候选保留；单张、多张出牌、声明杠和最终14个结构位置的合法和牌判定继续保留。
- 计分用的“重复触发”与“弃牌重抽”是不同机制。此次时间限制不禁止奇物在最终计分时重复触发。

### 阶段实现建议（待执行）

`进入本关 → 摸12张 → 起手准备（一次可选重抽＋已有改牌能力）→ 开始组牌 → 逐步出牌／声明杠 → 最终结算`

准备阶段建议提供明确的“开始组牌”按钮；确认后不可返回准备阶段。准备阶段不允许先出牌、补看未来牌后再决定重抽；声明杠造成入区、补牌，也须进入组牌阶段。恢复存档必须保留阶段和重抽是否已使用，不能靠刷新页面重复准备。

对“改牌也按照这个规则”的暂定解释是**限制使用时机**，不是将三种能力全部改为免费或各一次。仍需对应奇物；升降笔／换色绫每次1墨，百相玉每次2墨、每关最多一张，基础墨点沿用4作为待校准起点。准备阶段可在重抽前后使用，受已有资源限制；这部分解释尚非额外的用户数值确认。

一次重抽必须一次提交所选牌并等量补入，不能拆成多次操作。弃牌不回收。改过的牌若随后弃掉，已花墨点不返还。准备结束后遗留墨点不提供关内改牌入口。

### 新供牌量的准确口径

无杠时，本关最多看过的牌数为 `12 + 起手弃换张数k + 14 = 26+k`，其中 `0≤k≤12`，所以范围为26～38张；每声明一杠最多再增加1张实体牌及正常补牌，四杠理论上限42张。

**看过38张不等于可以从38张任挑14张。** 起手弃掉的k张已经不可用；无杠时最终成型区与候选区仍共26张。重抽发生在未知后续摸牌之前，最后出满14后的补牌也不能倒流用于修复成型区。后续概率模型必须模拟起手保留决策和出牌顺序，不能直接抽38张再挑最优牌。

### 四路线的影响与调参方向

| 路线 | 新规则主要影响 | 下一轮标定方式 |
| --- | --- | --- |
| 高番突破 | 起手可定向留同色／对子并改牌；中途无法追着缺张补救，九莲与役满可达性降低 | 用中档番型、高档番型、役满分别标定完整曲线；九莲保留为冲高分目标，不作为普通过关要求 |
| 刻子重触发 | 起手留对子较有价值；后续无法反复找第三张，四刻与杠更稀有 | 分别测2刻、3刻、4刻，不再把四刻或三节高当普通成型基线；先核算2～3刻的有效收益 |
| 留牌蓄势 | 不能胡后继续洗候选区，幺九保留与和牌所需工作空间直接竞争 | 比较6／9／10张幺九，12张作为极限；最后补牌可参与留牌计分，但不能再重抽或改成幺九 |
| 顺子成长 | 普通顺子较灵活，但连续多关四顺子假设更不可靠；改牌只能强化起手 | 计算2／3／4顺混合、未和牌关和重触发获取时机；先验证前期生存，再决定初值及成长次数收益 |

四条路线的条件得分公式不会仅因重抽时机改变而自动变化，但这些得分能否出现、出现几次会变化。因此暂不把1.35留牌系数、100或300成长初值、2048高番锚点和现行关卡门槛认定为已平衡参数。

借东风（增加换牌次数）、千层塔（换牌成长）、留白扇（剩余次数加底分）及第三关“少2次换牌”都受影响。实施前必须处理：建议暂移出新增奖励池或重做效果，不能用旧效果增加第二次起手重抽或重新开放关中重抽；存量持有与存档兼容也需明确。此处仅列影响和建议，没有修改这些奇物。

风险提醒也须更新：组牌阶段不能再提示“可花换牌或墨补救”。结构判断为仅靠追加无法完成时，应明确操作限制及诈胡后果，保留用户继续出牌的选择；未知牌墙仍不能被伪装成已证明无解。累计得分、诈胡扣分后仍可能过关的规则继续保留。

### 后续平衡工作（暂不执行）

1. 固定以上准备阶段边界，并以不同路线的起手保留策略重算合法和牌与目标条件的可达性；两模式分别统计，明确无改牌／有改牌及配件获取时机。
2. 在这些样本上比较每关贡献、累计达标、诈胡扣分和提前失败，不能把失败后的理论分数当实得分。
3. 再调核心、配件和两模式目标曲线。这里的“动态调整”是随规则变化重新标定参数，不额外引入对玩家隐藏的实时概率调整系统。
4. 经用户后续要求再实施；验收仍以真实浏览器试玩为主，只补必要P0回归，不新增一批模拟或自动化脚本。

## 本轮已完成试算：旧供牌条件的得分问题

### 完全零重抽的对照：已被最新规则替代

## 前一轮的装备与数值建议（供对照）

- 先采用4个总装备位：最多1件计分核心，其余3件自由放底分、重触发、改牌及资源辅助。计分核心指四条路线的主要放大效果，普通加底分、倍率、重触发不占另一种特殊槽。允许在关间更换核心，不锁定职业。
- 开局固定展示四方向的全部核心，四选一，不随机删去某条路线；选择后只有1件已装备奇物。第1～5关通过后，建议每关仅有一次新奇物选择。持续取得辅助且不换核心时，进入第1～6关的装备数量为 `1 / 2 / 3 / 4 / 4 / 4`。满槽后换装或跳过，无额外仓库。
- 免费奖励和商店不能各给一次。合并为一个3选1获取入口；若保留购买形式，购入或替换也必须共同消耗这一关的唯一额度。
- 第一次奖励至少提供一件该核心的基础联动件，让成长／重触发路线可以按计划启动；之后每次提供1件兼容项＋2件随机项。兼容项不是固定最优件，也不保证整套自动配齐。
- 留牌每次×1.3→×1.35、成长初值100或300及每次×1.2均保留作对照参数；当前未批准实施。下文旧供牌假设的试算不构成新起手规则的平衡结论。刻子每次×2、刻石+60与高番2048单点也待新供牌条件重算。
- 关卡目标本轮不冻结：同装备下的得分计算不等于各路线的真实成型率，更不等于累计通关率。

## 开局四选一与首关奖励

用户此前提出提高开局及首关后的成长核心刷新概率；最新的固定四选一使四条路线在开局的展示率都为100%，因此不再需要开局权重。展示率不等于选择率，玩家仍自行决定路线。

| 开局核心方向 | 给玩家的玩法说明 | 首关联动奖励的建议方向 |
| --- | --- | --- |
| 高番突破 | 追求大牌，用番数放大得分 | 改牌、换牌等成型辅助 |
| 刻子重触发 | 多做刻子和杠，叠加计分效果 | 刻子重复计分 |
| 留牌蓄势 | 和牌同时保留候选区的幺九牌 | 留牌重复计分 |
| 顺子成长 | 连续组成顺子，积累本局的永久底分 | 顺子重复计分，及早开始复利 |

四个选项展示奇物图片、简短效果和一个联动提示即可，不增加职业等级或新养成系统。所选核心占用普通装备位，并受“最多1件计分核心”限制；其余奇物可跨方向使用。关间仍可通过一次奖励机会更换核心，更换消耗当关获取额度，装备数量不会因此增加。

首关后的扶持应转向**所选路线的配件**。已选成长核心时，再提高同一核心的概率没有收益；建议首次3选1中有一个明确可用的基础联动项，成长路线优先提供顺子重触发。是否固定为指定配件仍是建议，需以玩法试验确认，不能把“提高出现机会”记成用户已批准的整套保送。

若玩家主动换入新的成长核心，只从取得后开始成长，不追补之前关卡。新核心的早期获取问题与重触发配件的获取问题分开处理；四选一解决前者，首关联动供给改善后者。

## 为什么现在第二关就有四件

当前引擎开局1件、8钱；首关达标获得9～13钱，再免费3选1，并进入可连续购买的商店。价格5～8钱，所以首关后至少17钱，常常可再买2件：

`开局1 + 免费奖励1 + 购买2 = 第2关4件`。

廉价组合甚至可以买满商店3件、达到5件；还可花2钱无限刷新，当前也无装备上限。只减少免费奖励、或只加槽位而不限制购入与替换次数，都不足以控制构筑速度。

| 装备上限 | 第1～6关装备数量 | 六关内开始取舍的时机 |
| --- | --- | --- |
| 4 | 1、2、3、4、4、4 | 第4关填满，第5、6关各一次换装 |
| 5 | 1、2、3、4、5、5 | 第5关填满，只有末次换装 |
| 6 | 1、2、3、4、5、6 | 通关前没有满槽替换压力 |

因此首轮选4格。四格仍能容纳“核心＋触发配件＋底分件＋成型辅助”；代价是不能再同时加入全部辅助。

## 每关一件的抽取概率

组合数动态规划精确计算，无蒙特卡洛、无随机种子。用28件全池作敏感性模型，**28不是已经冻结的新奇物总数**。已有核心，还需两件指定配件；每次抽3选1，优先拿目标，满4槽替换非关键物，换出物回到池中。下面均不包含付费刷新，不是游戏通关率。

随机模型：第t次选择时未持有池为 `n=N−min(1+t,4)`，缺k件时，没有任何目标的概率是 `C(n−k,3)/C(n,3)`。一次即使命中两件，也只能取得一件。

| 抽取方式 | 进入第3关拿齐 | 进入第4关拿齐 | 进入第6关拿齐 |
| --- | ---: | ---: | ---: |
| 全随机3选1 | 2.47% | 6.82% | 19.02% |
| 每次1兼容＋2随机 | 15.20% | 39.82% | 85.97% |
| 首次可选关键联动，其后1兼容＋2随机 | 31.00% | 57.83% | 91.21% |

兼容模型中，一条路线兼容池共6件：核心、两件指定配件、三件其他支持件；先从未持有兼容池抽1件，再从其余全池抽2件。没见目标时选兼容填充件，满槽换非关键兼容物。实际池大小、替代配件和玩家选择不同，概率会变，不能把91.21%当最终产品保证。

首次关键联动的建议用于保障启动，不直接送完整三件套；仍然是3选1，玩家可选另两件。之后不再增加另一套保底计数器或专属货币。若实际每条路线有多种可替代配件，按真实标签池再算一次。

4槽改5槽，在全随机28池模型中终局双配件率仅从19.02%变成19.30%。因此凑不齐主要是抽取方式问题，不能用放宽槽位来补救。

## 为什么建议最多一个计分核心

旧锚点下，指数核心＋两件留牌效果只占3格，却可有 `400×2048×1.3^24≈4.45亿`。成长核心＋顺子重复＋指数也只占3格。这表明4槽不能独立限制跨核心乘区。

这只是可组合的条件上限，不证明现实中所有人都会拿到，也不证明九莲与满留牌经常同时成型。但在尚未测得联合概率时，直接允许所有核心相乘，无法从单路线百万试算推导整体平衡。

因此首轮建议最多一个计分核心，辅助效果仍可组合：刻石既能服务刻子，也能为其他核心增加底分；换牌、改牌、普通成长和资源奇物保持选择空间。这里限制的是主放大机制，不是角色或职业。若后续要开放多核心，可作为独立高上限规则再验证。

## 金币与后续验证

取消无限购入后，原先每关9～13钱与2钱刷新不宜照搬，否则每次刷新都几乎没有机会成本。可先按“每关收入约等于一次刷新费用”试调，例如起始4钱、每关基础4钱、刷新4钱且每关最多一次；刻石等额外收入仍有价值。此金币数字只是配套候选，未纳入上表不含刷新概率，也未完成经济平衡。

下一阶段需把真实核心/支持池、各档指数曲线和四个槽位规则落成最小可试玩版本，再用相同种子、相同获取节奏，比较实际合法和牌率、达成目标条件的比例、每关贡献与累计通过率。浏览器试玩为主要验收；只在既有P0测试里补关键结算和抽取边界，不新增大量脚本。
