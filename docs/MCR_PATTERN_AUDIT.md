# 国标番型覆盖审计

2026-10-21。目录和判定的唯一数据源为 `dist/mcr-patterns.js` 的 `MCR_CATALOG` 与 `mcrPatterns`。目录完整列出国标 81 项：59 项可在本作触发，22 项保留说明但不计分；奇物额外番型不混入这 81 项。

## 依据与版本

- 世界麻将组织《麻将竞赛规则》，2021 年分发的中英日绿皮书，第八条的 81 番表、第九条计分原则、附件一的覆盖和牌例。[WMO 原站 PDF](https://www.mindmahjong.com/adobe/MCR2021.pdf)；本次实际读取 [洛桑麻将俱乐部保存的同名 2021 规则 PDF](https://mahjongclublausanne.ch/wp-content/uploads/2024/03/Greenbook2021_Chinese-EN.pdf)。该分发文件版权页标注第二版 2014 年，不将“2021 文件名”误称一次另行修订。
- 固定文档 SHA-256：`77220856f7d02a9d108cb4046038102ac46a9271ed2baf48b383cb13691be01c`。
- 交叉检查 [北京大学 PyMahjongGB 的 fan_calculator.cpp](https://github.com/ailab-pku/PyMahjongGB/blob/master/MahjongGB/mahjong-algorithm/fan_calculator.cpp) 与其番表。只参考和验证算法关系，没有引入该库、复制其 C++ 源码或扩展它的非 81 项规则。主源有明确规定时以主源为准。

主源与旧实现的差异已逐项处理：双暗杠目录为 **8 番**；清幺九可加双同刻或三同刻；九莲宝灯不计幺九刻。国标七对可由四张相同牌组成两个对子，并可计四归一。2～8 连七对可加断幺。全不靠含完整九张组合龙时可同时计组合龙。

## 本作的明确适配

本作是单人构筑，不区分明暗，也没有他家舍牌、荣和/自摸来源、圈风、自风、唯一最后和牌张、牌河、海底及花牌。不能把出牌先后等同于对局时机，也不能将普通刻子或已声明的杠自动视为暗刻、暗杠。目录逐项解释缺少的前提。

九莲宝灯采用最终牌面条件：普通结构、无杠、同花色 `1112345678999` 再加一张。不推断九面听，也不额外赠送门清或不求人番。无番和采用“无其他本作可用国标番型”的 8 番兜底，不声称已排除未建模的等待形或时机番。游戏使用肉鸽分数与闯关门槛，不增加竞技国标 8 番起和门槛。

按用户追加的难度准则复核：四暗刻、三暗刻、双暗刻、暗杠、双暗杠，以及门前清、不求人、自摸等，均为 `unavailable`，不因本作没有对手而自动成立。明杠、双明杠、全求人同样保留目录但不计分；已经支持的三杠、四杠只数实际声明操作，不推断明暗。清一色、九莲、七对等仍要求具体牌面组合，予以保留；国标平和也必须有四顺子与数牌雀头，不能由“单人组牌”自动取得。没有根据缺少的明暗流程虚构高番，也没有用未验证的胡率数字作难度结论。

传入的结构由和牌拆分器保证合法：

- `normal`：四组面子与雀头；声明杠为四张同牌的一组。
- `pairs`：七个二张组、空雀头，允许两个同名对子。
- `orphans`：一个十四张组、空雀头。
- `knitted`：一个九张组合龙组、一个三/四张面子组、二张雀头。
- `unconnected`：一个十四张互异牌组、空雀头。

覆盖表负责不重复计分；面子关系组合另行求可计的最大番数。四组高番关系不再拆回内部低番；三组关系的第四面子最多额外套算一次。只有两组关系时，枚举面子关系的无环组合；同种低番不能复用同一面子。七对、十三幺、不靠都按各自解释计分，不能从一份解释拆出另一份解释的面子番型。

改牌允许有效牌面超过四张，沿用本作既有规则。大三元、小三元、大四喜、小四喜按不同箭牌/风牌种类判定，重复同名刻子不能冒充另一种牌。国标箭刻、幺九刻按实际面子计次。极端改牌例：十八张全發、已声明四杠，可计绿一色、四杠、字一色与四组箭刻，共 248 番；这是改牌产生的本作牌例，不是正常麻将牌库能出现的牌例。

## 验证范围

已做模块直接调用核对：81 项目录唯一性与 59/22 状态计数、用户截图的混幺九、清幺九与双同刻/三同刻、国标四同牌七对/四归一、九莲宝灯、组合龙加平和、组合龙含杠、全不靠加组合龙、重复顺子的有限套算，以及重复箭/风牌不得冒充三元/四喜。13 组核心断言与补充的重复牌面断言通过。未新增自动化脚本。整体 P0 计分回归与实际浏览器试玩由集成会话负责，不以这份模块核对代替试玩验收。
