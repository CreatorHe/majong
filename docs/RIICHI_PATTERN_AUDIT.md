# 日麻役种覆盖核对

更新：2026-10-21。对应实现：`dist/riichi-patterns.js` 的 `RIICHI_CATALOG` 与 `riichiPatterns(groups, pair, shape)`。

目录按雀魂常规役种的使用习惯组织，条件与普通役翻数对照 [EMA 2025 官方规则的役种表及第 4.2 节](https://mahjong-europe.org/portal/images/docs/Riichi-rules-2025-EN.pdf)，并参考 [WRC 官方规则入口](https://www.worldriichi.org/wrc-rules)。雀魂提供的[官方入门页](https://mahjongsoul.com/startguide/)用于产品入口参考，其静态网页没有完整可抓取的役种清单，因此不把它当作全部规则已逐条核验的证明。大四喜按本次确定的雀魂口径采用双倍役满，与 EMA/WRC 口径有区别。

## 本作适配与边界

- 本作是门清自由构筑，清一色、混一色、一气通贯、三色同顺、混全、纯全采用门清翻数；一盃口、二盃口及九莲的门清前提按该适配处理。
- 门清构筑不能替代暗刻来源、荣和／自摸或和牌张记录。因此三暗刻、四暗刻、平和及待牌型双倍役满不从最终成牌猜测；声明杠也不自动获得岭上开花。
- 普通役满折算 13 翻，大四喜折算 26 翻；多个真实役满可复合，役满覆盖普通役。13 翻及以上的普通役合计不额外生成“累计役满”，也不追加翻数。指数倍率由引擎统一处理。
- 三种秘卷仍提供已定义的额外倍率，不偷换为 13 翻役满，也不直接写入基础役判定结果；由引擎验证持有奇物后应用。
- 九莲必须无杠、全手同花色，严格包含 `1112345678999` 并只多一张；国士必须六种一九牌与七种字牌各有一张，仅一种重复。单凭成牌不推断九面听、十三面听。
- 三元、四喜、三色同刻按不同牌面集合识别。改牌可能突破同牌四张的常规牌山限制，重复同种刻子不能伪造“三种”三元牌或“三色”同刻；同一种三元牌也只计一次役牌。
- 混老头可复合对对和或七对子，不能再叠混全带幺九；混全和纯全必须含顺子。二盃口替代一盃口，并与七对子采用不同拆分解释，由引擎择高。

## 核对结果与验收职责

已做一次临时 Node 断言检查，未新增测试脚本：用户截图识别为混老头＋对对和；小三元复合两种役牌；清老头仅返回役满；大四喜与字一色复合；九莲与国士特殊结构成立；重复白刻子不误报三元。

完整计分、指数倍率、最佳拆分与图鉴 UI 由主任务集成后在已有 P0 回归和实际浏览器中验收。此记录不把模块断言视为浏览器验收通过，也不代表尚未记录的传统对局规则已实现。

### 单人模式难度适配

不因没有对手或鸣牌而自动赠送门清、暗刻或自摸奖励。四暗刻、三暗刻等当前停用。清一色、九莲等仍由具体牌面约束成立；现用门清翻数仅为暂定奖励口径，不能视为已验证的竞技胡率或本作难度。后续以新版实际试玩数据调档，本次不臆测真人胡率。
