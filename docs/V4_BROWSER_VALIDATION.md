# V4 刷牌与构筑提示验收

2026-10-21，在本机 Codex 内置浏览器逐步操作。复用 `tests/browser-harness.html` 准备明确的牌局，不以场景牌局推断真实胡率。临时入口已从发布源移除。

| 场景 | 可见结果 |
| --- | --- |
| 国标新开局、单张入区 | 初始候选 12、换牌 7、墨 4、牌山 124；出 1 张后其他 11 张保留，补 1 张，牌山 123 |
| 主动换 2 张 | 换牌剩 6，牌山 121，候选仍为 12；其他候选保留 |
| 日麻七对差最后一张 | 成型 13 张时车轮目标为 6/7，候选区的八筒不提前计入；没有“已触发”计分奇物 |
| 补齐八筒 | 成型 14 张，牌山 111→110，候选仍 12；圆镜、成双玉、回响铃、车轮秘卷共 4 件点亮；预览为底分 480 × 101.823375 = 48,875（向下取整） |
| 刷新续局 | 继续后同一牌局、同一预览与 4 件联动恢复 |
| 将成型八筒改九筒再修复 | 改坏后显示真实炸胡预览，计分联动熄灭且仍可改牌；九筒改回八筒后 4 件联动和 48,875 预览恢复，两次各消耗 1 墨 |
| 和牌、跳过演出、领奖、进入下一关 | 最终显示 48,875，与预览相等；奖励和商店流程通畅；第二关累计保留 48,875，候选 12、牌山 124、换牌 7、墨 4、成型区清空 |
| 4 张候选直接声明杠 | 原成型 5 位置变 8 位置／9 实牌；牌山 119→115，候选仍 12，未用候选保留；四方鼎提示 1 杠，连山印材料提示 1/3，尚未合法和牌时不提前记分 |
| 第三关初始资源 | 候选 12、牌山 124、换牌 5、墨 4，与“初始换牌减少 2 次”一致 |

现有 `npm test` 全部通过；新增自动化仅补入已有 P0 文件，未新增测试脚本。核心覆盖候选保留与曝光上限、杠与成型替换、版本隔离、实际结算联动、非法和牌提示及埋点版本兼容。
