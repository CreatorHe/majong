# V5 四路线数值报告

日期：2026-10-21。状态：**可试玩候选，不是成熟平衡结论**。最终参数以本报告及 `dist/balance.js` 为准；原 ×3.2 刻子、全部留牌统一 ×1.22 的确认样本保留作探索比较。完整机器数据见 [v5-balance-data.json](v5-balance-data.json)。

**最重要的风险是成型，不是门槛。** 本轮在线策略首关只有约 39.2%–39.6% 合法和牌；超过半数起手会在首关诈胡结束。降低门槛不会把诈胡变成合法和牌。这是一个只看可见牌、存在策略局限的程序结果，不能当作真人胡率，也不能用它宣称难度已合适。实际浏览器试玩另由主会话验收。

本报告把“从开局的真实期望”“进入某关后的条件分数”“给定成型牌的理论能力”分开报告。它们不能互相替代。失败后立即截断；不假定每局都拿齐配件、每关都做满配大牌。

## 冻结规则与参数

每关12张候选，只在准备阶段最多5次、每次弃换1～5张；进入组牌后按打出数量正常补牌。普通改点/改色/万能也限准备阶段，无成型区替换。大番核心与补缺符同时持有时，组牌未满14可使用一次专用补缺：换≤3张，或耗1墨改一张数牌点数±1/花色；可改候选或成型牌，二者共用一次。

开局四选一核心，核心整局固定。最多4槽、1核心；每次过关只得1件，奖励三选一含1个兼容项，首关保证各路线关键补缺/重触发。满槽时替换或跳过，无商店额外买入；非大番不出现补缺符、非留牌不出现余音扇。第1～6关的槽位曲线为 **1→2→3→4→4→4**。

| 参数 | 最终值 |
| --- | --- |
| 普通倍率 | 国标 1 + 番/8；日麻 1 + 翻 |
| 刻子核心 | 每个刻子/杠事件 ×2.8 |
| 留牌核心 | 前9张候选区幺九每事件 ×1.22，第10～12张每事件 ×2；按实体顺序分档，复触沿用同档 |
| 成长核心 | 初始 200 底分；每次合法顺子事件 ×1.17，跨关保留 |
| 重触发 | 面子或留牌额外一次，不递归复制自己、不重复发钱 |
| 温玉/刻石 | 80 整手底分 / 每个刻子事件 60 底分 |
| 墨/末关 | 每关4墨；绝顶倍率 ×0.8 |

两模式均使用同一条累计门槛，各路线不设专属门槛。它是累计分，不是本关必须赚到的分数；诈胡扣本关门槛的10%（向上取整），扣完累计仍达标就过关。

## 样本与算法

最终确认集每模式、每路线1000局，共8000局。此前探索了多轮候选，前一确认集揭示了刻子尾部过强及留牌缺少大数字两个实质问题，因此又补了训练敏感性。整个过程并非事前预注册的一次holdout。最后固定组合后跑全新 confirmation-v2 种子，只确认、不再选参数；此前各组均单独存档。

- 确认分组：`confirmation-v2`。种子为 SHA-256(`jade-v5-20261021/分组/序号`) 前4字节的小端无符号整数，序号0～999；各路线/模式同种子起跑。奖励使用真实引擎RNG，所以路线产生不同选择后不要求后续牌墙完全相同。
- 实际调用 newRun → chooseStarter → exchange/transform → beginPlay → commit/highRescue → preview → settle → finishSettlement → chooseReward/skipReward → nextRound。
- 准备策略保护互不重复的面子、雀头和搭子；普通出牌优先完整面子，有限枚举可见牌中最多16个完成解释，必须保留全部已成型牌。并非先看完整牌墙再挑牌。
- 按路线偏好选择刻子、顺子、保留幺九或高番。大番在已有补缺符时会搜索可见改牌来完成/提高番；日麻优先减少幺九以支持断幺。起手已拥有升降笔/换色绫才可按墨量使用。
- 每关只选实际奖励中的一件；优先关键重触发/补缺、改点与底分，满槽择优替换。实际失败即停止，不额外发配件；成长只由合法结算写回。
- 本策略没有使用杠、万能牌，也没有专门追国士/九莲等稀有牌；这低估部分高阶人类策略，但不能给未知提升虚加分。
- 成功率95%区间用Wilson；期望分均值另给2000次bootstrap区间。稀少极端分数会使均值区间很宽，零次出现也不意味着概率为零。
- 临时脚本只放 /tmp/jade-v5-balance，未增加正式自动化脚本或测试文件；5份实际分析源码全文、原始SHA-256、Node版本、可复制的提取/运行命令及绝对路径替换说明均保存在JSON的 `repro.sourceArchive` / `repro.extractAndRunRecipe`；无需依赖临时目录继续存在。

## 实施边界与下一次判断

本轮调整没有引入额外保底、概率叠层、连锁触发递归、路线专属门槛或商店补发。4槽与每关一件已经足以产生选择，不需再加系统。普通倍率线性、大番独占分段指数、其它路线靠事件与成长，这四个入口在同一实际计分器内结算。

当前应重点试玩三件事：首关连续失败是否挫败；补缺与起手改牌是否可理解；同样一套构筑在普通牌与成型牌之间是否有清晰可感的爆发差距。数值尚存在路线稳定性和极端分数差异，不宣称已达到竞技公平。稀有牌、万能和杠的人工策略未由本次采样充分覆盖；不能根据0次观测移除这些能力，也不能把理论百万样例当作常见收益。
