## 环境观察与验收边界

本地 Cloudflare 服务 `127.0.0.1:4175` 的响应头检查确认静态资源使用 `max-age=0, must-revalidate`。实际生产构建正常局随后在 `4187` 验收；这里没有声明线上版本已发布。

旧 Python 静态服务 `4180` 曾出现模块混合缓存导致的 NaN，属于验收工具环境混用，未计入游戏随机失败或游戏缺陷。切换到一致生产构建后继续验证；没有为此新增缓存框架。

三个数据层必须分开：

1. 方案中的 8,000 条冻结模型旅程用于数值估算，其有限策略、未覆盖能力和抽样边界仍按原方案说明。

3. 正常随机浏览器功能旅程用于验收实际操作链路，每路线一局不能确认四路线平衡，也不能替代后续每路线至少 10 条新增完整随机旅程。
