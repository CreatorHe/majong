# 高难度模式与轻松模式隔离方案

本次新增可独立游玩的 V5 高难度模式，当前 V9 轻松玩法保持不变。首页以红紫色「高难度模式」入口进入 `/hard/`，高难页可以返回轻松模式；两个入口各自保留旅程。

## 权威基线

- 轻松模式：`cfaf4e3`，V9 九张整批刷新、固定基数与番型倍率、纯辅助奇物及双模式门槛。
- 高难模式：`a31de09`，完整 V5 四路线实现。数值以该提交的引擎和 `docs/V5_BALANCE_REPORT.md` 为准，不带入 V6 到 V9 的改动。

## 高难度玩法

国标、日麻均可选。开局四选一核心：大番、刻子、留牌、成长；最多四件奇物、一个固定核心。六关累计门槛为 200、500、1000、2500、5500、12000。

每关十二张候选，出几张补几张，其余留在手边。准备阶段最多五次弃换，每次一到五张；普通改点、换色和万能牌也仅准备时可用。无成型区弃除或替换。大番核心与补缺符的专用补救、单张过程得分、杠、合法和牌、诈胡扣分后溢出过关、路线成长与重触发、奖励替换均恢复 V5。

过关每次获得一件，最多四槽；首关保证路线关键配件，后续按原版兼容奖励规则。完整四路线的倍率、底分、增长、末关系数与基础／解锁番型沿用 V5，不在此次顺带重新平衡。

## 隔离边界

- 引擎、平衡、判型、番型目录、构筑提示、图鉴、页面控制器各使用 `/hard/` 内独立模块；不将模式分支塞入轻松引擎。
- 轻松存档仍为 `jade-run-v9`；新高难存档为 `jade-run-hard-v5`，不读取或覆盖历史 `jade-run-v5`。高难引擎校验 `variant=hard_v5`。
- 美术和演出可共享只读资源，游戏状态、计分、存档、声音偏好分别归属页面。切换入口不结束另一模式旅程。
- 统计必须把新高难、现有轻松和历史版本区分开；看板按模式分别查询，不将两种模式的分数、胜率、番型或路线混池。

## 验收与发布

保留现有 P0 回归，补充 V5 规则恢复、跨模式存档拒绝与统计隔离用例，不增加模拟平衡脚本。浏览器验证轻松九张整批、新高难十二张保留补牌、双模式入口、四路线选择、准备阶段限制、和牌计分、奖励与下一关、返回及刷新恢复。规则实现与历史基线做差异审计。

完成整体 Review 后部署现有站点，线上再确认两入口及核心操作，保存真实结果与未覆盖范围。门槛、抽牌概率与大牌难度本轮不作调整。
