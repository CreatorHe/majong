# 大番核心绑定同点三色万能牌：模型比较

本文为冻结模型报告副本。全部源码、原始数据及 SHA 清单位于工作区 `outputs/v7-wild-core-20261022/routes/`，文中的数据文件名均相对此目录；轻量汇总另存 `docs/v7-balance-data.json`。

日期：2026-10-22。仅分析副本，不是线上试玩。正式 V6 计分、倍率、6关门槛、12张候选、136张实体牌、每关2墨/一次编辑全部未改；仅改能力权限和奖励池。

## 方案与固定策略

- current：百相玉保留原全局奖励池，持有后才可改万能牌。
- exclusive：百相玉只对大番刷新/装备/使用，仍占槽；首关保底补缺符不变。对大番自身，该方案规则与current一致。
- integrated：大番核心开局直接提供同点数三花色万能能力，不占额外槽；百相玉退出全局奖励池。仍共用每关一次编辑，不能编辑字牌、不能跨点数。
- integrated-occupied：仅用于分析的消融对照，开局提供百相玉并占1槽。与integrated都有首关能力，但少一个配件位置；不是另一个推荐实施方案。
- K0没有成型牌弃除；K2为整趟一次，单次永久弃1–2张，不立即补摸，后续正常出几补几。仅在可见候选和剩余编辑能确认完整合法补救时使用。
- 策略先走正常组牌，至少已有8张成型牌后，尝试有可见合法完成解的共享编辑。万能牌真实调用transform wild，再枚举该实体牌三种有效花色；visibleFinish返回实体ID，commit仍提交原实体，正式结算自行选择最佳合法赋值。弃除联合编辑也走同一流程。
- 不提前把牌变万能来等待未来好牌，不主动拆合法牌冲番，不偷看牌墙，不做杠。不能据此证明高番最优玩法、真实玩家胜率或稀有牌上界。
- 固定大番奖励优先级为补缺符→百相玉→升降笔（代码rank_brush）→温玉→换色绫，其余沿用旧顺序。现行与独立共享排序；合并池没有百相玉。旧排序200先导发现百相玉常被很快替换，故在独立确认种子运行前明确冻结该wild-aware策略，确认期间没有按结果改策略或参数。此排序不宣称是全局最优玩家选择。

## 样本与独立版等价验证

- 主确认：每条件1000个固定随机种子，共6条件6000趟，逐趟实际运行正式结算并在失败处截断。确认种子独立于200先导。
- exclusive没有伪造另外1000个独立样本。旧排序200先导中current/exclusive逐项一致；又使用主确认的前200个相同种子、wild-aware排序重放exclusive-K0/K2，400趟所有逐关字段与current对应记录完全一致。独立版表中的大番结果引用等价的current对照，不能加进样本总数。
- 所有得分均为全开局最终累计净分，包含失败与诈胡扣分。95% Wilson仅反映固定策略随机种子的抽样误差，不包含策略和人类水平偏差。

合并版“持有百相玉=0”表示能力来自核心而不是道具，所有开局都有能力。独立版K2有795/1000趟获得玉，首次持有分别在R3/R4/R5/R6为287/298/149/61趟；首关保底补缺符且一次只拿一件，所以该策略前两关无法持玉。使用次数不等于独立新增和牌次数：部分时候普通改点数也可能达到相同结局。

消融对照K2中，开局有万能但占槽通关54.5%，合并不占槽61.2%，相差6.7个百分点；无弃除相差6.2个百分点。首关合法率在有无槽位占用之间完全相同（K0均82.8%，K2均90.7%），区别从配件选择开始出现。省槽有实质收益，尤其能保留温玉等加分配件；不能把它称为严格的唯一中介因果量，因为配件选择和后续伪随机牌墙路径也会分叉。

在K2主对照中，合并相对现行最终均值增加89,778分、中位增加46,320分；新增首关可用性和免占槽都贡献收益。没有增加普通牌型倍率或万能次数。

## 局限与其他路线

- 旧奖励排序pilot200只作探索，不能与确认集直接混池；当前wild-aware排序主动保留独立百相玉、牺牲部分底分配件，不是“最佳现行玩家”证明。报告评价固定透明策略，而非夸大精确胜率。
- 主试验只针对大番。合并版从全局池移除百相玉也会改变其余路线的奖品构成；另补other-routes1000同种子K2对照，其结果在单独文件汇总，不把大番结论外推。
- 万能动作只在有当前可见完成解时触发，未优化提前使用、稀有大牌追求或实体排放方式；更会组稀有牌的策略需要单独压力试验。

## 同口径四路线合并版观察

四路均为整趟K2，每路线1000同种子、既定路线策略。大番通关61.2%，刻子58.7%，留牌77.4%，成长75.7%。可以据此说大番与自身对照相比改善，不能据此说四路线已精确平衡；本策略专注可见合法和牌，没有专攻九莲等高番上限，路线偏好和计分长尾仍影响比较。
