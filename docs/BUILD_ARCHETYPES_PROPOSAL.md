# 多流派大数字构筑方案（讨论稿）

> **V5最终试玩版已实施（2026-10-21）**：以 [V5数值报告](V5_BALANCE_REPORT.md)、[README](../README.md) 与 `dist/balance.js` 为当前规则。下文保留历史计算和方案，含“先不执行”“六槽”“一次任意换牌”“关间换核心”等旧提议，均不再生效。当前为5次开局各≤5、普通改牌限开局、大番核心＋补缺符一次例外、4槽1固定核心、每关一件；最终倍率与门槛以V5报告为准。


2026-10-21。用户最新方向：保留大数字与冲高分目标，将高番指数计分改为奇物能力；普通情况下采用底分与温和牌型倍率，再提供其他高分路径。用户进一步指定参考小丑牌的重复触发、留牌计分、概率强化和永久成长。

本文件是设计建议，不是已实现或已验证平衡的规格。此前“只降低牌型倍率、终关约4万”的建议不再作为主方案。现有游戏代码、21件奇物和目标均未修改。

**最新计划，暂不执行：** 用户认可四路线及最多1个计分核心，开局固定展示四个核心、四选一；最新又确定每关仅起手阶段可进行一次任意数量弃牌重抽，点数／花色／万能牌修改也只在起手阶段，成型区替换停用。详见[四流派平衡与奇物获取节奏](BUILD_BALANCE_AND_RELIC_PACING.md)。4槽、每关一次获取和首关联动配件仍是配套建议。旧供牌条件的核算已暴露成长100前期失败等不平衡，1.35留牌系数与100／300成长初值均需在新规则下重算，未定版。下文6槽、核心自由叠加及旧数值保留为前一版设计过程，不能视为最新已定规则。

## 共同计分基础

普通计分沿用待讨论的线性映射：国标 `1+番/8`、日麻 `1+翻`；先识别合法和牌及番种，再由奇物改变牌面计分、成长、牌型倍率和重复次数。指数只在获得对应奇物后启用，不给所有牌型默认附送。

所有路线最终都完成14个结构位置的合法和牌。过程分不重复入账，诈胡仍按累计分和当前门槛处理。留牌指和牌时仍留在12张候选区的牌，不另造一套手牌区。

大数字的初步目标：3～4件匹配奇物与相应打法能形成十万至百万级收益，较少配件先有可感知收益；极端混合构筑可以冲更高纪录。这里的件数和数量级是调参目标，不是已经验证的获取概率或通关率。

## 路线一：高番突破

- 玩家重点：保留改牌资源，追求高番、稀有复合、役满；复用升降笔、换色绫、百相玉和现有秘卷。
- 新核心暂名“天机算筹”：把牌型倍率转换为指数曲线。只处理标准番型产生的倍率，不对最终得分、奇物加倍率或整串乘数再次指数化。
- 建议将高番核心按两模式相近难度分别标定。原公式下国标88番是2048倍、日麻单役满是约90.5倍，不能照搬这个22.6倍差距。
- 数量级示例：500底分×2048牌型倍率＝1,024,000。2048在此只是高番成型锚点，不是批准直接恢复旧曲线。
- 指数奇物必须对低番缺乏足够吸引力，并承担装备机会成本。可比较“普通占1格、曲线较温和”与“强转换占2格”两个参数方案，再选一个；首版不同时引入多种指数核心。

## 路线二：刻子／杠的重复计分

- 玩家重点：提高刻子、杠的数量；牌型本身不用达到役满。
- 复用刻石、连山印、四方鼎。新增一个“刻子计分时乘倍率”的效果，以及一个“刻子额外计分一次”的效果。名字待美术确定。
- 示例起点：每副刻子计分时倍率×2；重触发奇物使该面子再计分一次。刻石的+60底分属于面子计分效果，可随该面子重复，但金币奖励仍每副实际面子发一次。
- 四刻有8次计分，乘算共 `2^8=256`。在32番的手牌上，数牌基础240＋刻石`4×60×2=480`，得 `(240+480)×5×256=921,600`。
- 示例牌形为222万、333万、444万、555筒、66索；基于原有刻石数值和新拟的两个效果。不是当前游戏能直接得到的分数。
- 杠可以是这条路线的强化条件，如额外一次面子计分；不要首版另造全套杠职业。要确保两杠已有收益，而非只有四杠才有价值。

这条路线借鉴“照片提供乘算、查德增加触发次数”的分工。强连乘优先按四副面子计数，不把每副×2机械扩大为14张牌各×2。

## 路线三：留牌蓄势

- 玩家重点：组出能胡的牌，同时在候选区留下有价值的牌。放弃部分候选灵活性，换取最后的倍率。
- 新效果A暂名“藏锋”：最终候选区每张幺九牌给倍率×1.3，幺九包含数牌一、九和所有字牌。
- 新效果B暂名“余音”：留在候选区的计分效果额外触发一次。
- 9张幺九、每张触发2次时：`400×5×1.3^18≈224,911`。
- 12张幺九、每张触发2次时：`400×5×1.3^24≈1,085,602`。
- 未拿到留牌奇物时，候选区本身不计分。效果只检查最终快照，不按出牌点击次数累积。
- 最后一次出牌后的正常补牌也属于最终候选区；预览和结算必须使用同一快照。万能牌沿用本作定义，只认一种已确定有效牌面，不多算花色或把非一九点数变成幺九。

这条路线借鉴男爵与默剧演员：手中保留的牌从“没打出去的废牌”变成得分资源。12张幺九是完整成型上限示例，实际可达性须按保留候选、换牌和改牌规则试玩，不能用随机抽12张的概率代替。

## 路线四：顺子永久成长

- 玩家重点：较早选定顺子方向，持续积累；重触发既提高当手收益，也加快后续成长。
- 优先改造流云梳，不同时新增牌型等级、成长货币和跨局卡牌养成。可把永久底分存于奇物本身，避免每关重建牌墙后无法追踪实体牌。
- 提议效果：储存底分从100起，每组顺子实际结算使储存值×1.2；该效果明确允许面子重触发带来的额外成长。每手处理完成长后，只将最终储存值加入底分一次。
- 从第2关开始，5手、每手4顺子且每副计分2次，共40次有效成长；`100×1.2^40≈146,977`底分。加基础240、普通倍率6，示例约883,303分。
- 缺少重触发时，同样5手只有20次，储存底分约3,834。这体现配件质变，而非拿一件成长奇物就自动百万。
- 上述×6为数量级演算，未绑定特定番型；未计第六关×0.8及其他辅助效果。最终参数需按可实现手牌和获取时机复算。
- 成长型方向须在前两关有合理获取机会；不能只在第5关随机给出后声称与其他路线等价。首轮优先测试定向成长，不按免费单张点击数量成长。

这是新效果草案，现有流云梳仍是每顺子+8；不应将上述分数标为现有构筑的实测收益。

## 可混搭的概率支线

可借鉴血石＋概率翻倍＋重触发，但不急于独立做第五套职业：

- 指定花色牌计分时50%概率×1.2。
- 概率强化把所注明概率翻倍，最高100%。
- 该牌的重触发再独立执行一次已定义的计分效果。

14张均符合且变为必定触发、每张两次时，乘算为`1.2^28≈164.84`；若照搬每次×1.5，会变成约85,223倍。麻将的触发规模必须重新标定。

概率支线可放第二批：预览需明确显示期望或范围，不能把期望冒充保证得分；确认结算后随机结果冻结并只入账一次，刷新不能重抽。首轮可先验证确定性的面子、留牌和成长联动。

## 装备取舍与触发边界

1. 推荐所有奇物共用6个装备位，包含改牌和换牌辅助。先不强制核心互斥或选择职业，允许高番与留牌等混合。获得新奇物超额时交换或出售；计分核心应在商店阶段固定，不能在预览后免费轮换收集所有收益。
2. 六格本身不保证平衡。旧国标指数与满留牌直接相乘，`400×2048×1.3^24≈4.45亿`，说明还要按相同配件数、获得时机、换牌与墨预算校准指数强度。强混合可作为冲纪录目标，不能把极限收益当作关卡必需。
3. 重触发只重算指定牌／面子的计分效果；不重新判定整手番种，不重复发金币、发奖或再结算整手。是否允许永久成长须由具体效果明确声明。
4. 先确定所有额外次数，再执行效果。重触发不能再次生成重触发，防止递归循环；每件奇物有清晰触发对象与阶段。
5. 不靠拆成14次单张点击额外赚成长。同一最终状态下，仅改变点击批次不能获得上述路线收益。现有独行印仍是写明规则的独立过程奖励。
6. 结算可以展示多次触发，但累计入账、永久成长写回、通过判定只提交一次；预览本身不成长、不发钱。

## 平衡和验收顺序

先比较四条路线在同等装备预算下的半成型、成型和极限值，再标关卡曲线。百万级目标保留，上轮建议的4万终点暂停。仍按累计分过关，不新增“每关必须贡献多少分”的隐藏条件，也不因玩家爆发而动态抬高已固定的门槛。

首轮建议：线性基础计分＋一个高番指数核心＋面子重触发＋留牌计分；顺子成长复用流云梳，并围绕同一重触发机制扩展。概率强化、复制其他奇物等复杂交互后置。具体新增件数、装备位和数值均待方案讨论，不视为用户已经批准实施。

主要验收依赖当前刷牌规则下的真实浏览器试玩。只在现有P0测试中覆盖结算唯一性、重触发边界、增长保存、预览一致性、候选快照与诈胡累计边界，不新增大量脚本。
