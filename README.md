# 叠雀 Web 原型 · V5

单人麻将肉鸽。选择国标番型或日麻役种，自由出牌构成完整麻将手牌，用奇物、改牌和换牌提高得分，累计分达到六关逐步提高的门槛。

V5 已实现四核心构筑、开局准备、每关一件奇物及实时结算演出。最终试玩参数与 8,000 局确认数据见[数值报告](docs/V5_BALANCE_REPORT.md)，实际浏览器结果见[验收与 Review](docs/V5_BROWSER_VALIDATION.md)。当前是可试玩候选，首关成型和路线尾部仍有明显差异，不宣称成熟平衡。

## 本地运行

完整数据服务需要 Node.js 22.13+，游戏使用原生 JavaScript，服务端为 Worker + D1。

```sh
npm install
npm run dev
```

游戏地址：`http://127.0.0.1:4175/`，统计页：`http://127.0.0.1:4175/analytics/`。启动命令会构建并应用尚未执行的本地数据库迁移；本地数据保存在 `.wrangler/state/`，与线上数据库隔离。

只预览玩法可使用 Python 3：

```sh
npm start
```

打开 `http://127.0.0.1:4173/`。纯静态入口不含采集数据接口。游戏进度保存在当前浏览器；停止预览按 Ctrl+C。

## 部署

项目使用 Vite、Cloudflare Workers 和 D1。Node.js 需为 22.13 或更新版本。部署前安装依赖并登录 Cloudflare：

```sh
npm install
npx wrangler login
npx wrangler d1 create jade-run
```

从 `d1 create` 的结果复制数据库 ID，然后设置 `CLOUDFLARE_D1_DATABASE_ID` 并运行部署命令：

```sh
CLOUDFLARE_D1_DATABASE_ID=<你的数据库 ID> npm run deploy
```

部署脚本会构建 Worker 和静态资源、应用 `drizzle/` 中的远程迁移，再发布 Worker。游戏和 `/analytics/` 共用同一域名；匿名统计由 D1 保存。数据库 ID 只需在本地 shell 或部署环境变量中设置，不要提交到仓库。只需托管纯静态文件时，`dist/` 可交给任意静态文件服务器，但采集接口和统计页需要 Worker 才能工作。

## V5 当前规则

- 国标、日麻自选。游戏内番型图鉴列出直接支持、奇物解锁及本作不适用的项目。本作没有自摸／荣和、立直、明暗刻历史或指定和牌张，不凭空判定这些条件；不要求八番起和或日麻有役，不模拟竞技支付点数。
- 每关12张候选，准备阶段最多5次、每次换1～5张。普通改点／改色／万能也限准备阶段，须有对应奇物并消耗墨点。点击“开始组牌”后关闭普通换改；未用机会不结转。
- 单张或多张均可提交，出几张补几张，其他候选保留；成型区按牌面排序，不能替换。最终14个结构位置判和。显式杠用4张相同牌占3位置，实体完整手为14＋杠数张，杠锁定后不可改写。
- 大番核心搭配补缺符，组牌阶段未满14时可额外操作一次：换最多3张候选，或花1墨改一张候选／非杠成型数牌的点数±1或花色。两种方式共享一次额度，不可制作万能牌。
- 开局四个核心选一，整局固定，最多4件奇物且只有1核心。第1～5关通过后各三选一，可跳过；满槽明确替换辅助，不能换核心。关间不再额外购买。持续领奖时装备曲线为1／2／3／4／4／4。
- 首关奖励保证一个本路线的关键配件选项；之后包含1件兼容项和2件随机可用项。展示不等于自动获得，玩家只能选一件。停投借东风、千层塔、留白扇；非大番不出补缺符、非留牌不出余音扇。
- 花色万能牌保留点数，只代万／筒／索，不能代字牌；每关最多制作一张，最终身份由最佳合法解释统一决定。
- 有风险的出牌会提醒并允许明确确认。满14后计算所有有效奇物和万能解释，仍不能和牌则为“诈胡”，扣本关门槛的10%（向上取整）。扣分后累计仍达标也过关；每关只结算一次。

## 四条计分路线

普通倍率：国标 `1＋番/8`，日麻 `1＋翻`。只有天机算筹采用高番分段倍率；具体档位及超过役满后的线性尾部见[数值报告](docs/V5_BALANCE_REPORT.md)。普通牌型不会让其他奇物再次指数化。

| 核心 | 规则 |
| --- | --- |
| 天机算筹 · 大番 | 按最终番值进入高番倍率档，借补缺与改牌构筑稀有牌型 |
| 叠岳印 · 刻子 | 每个刻子／杠事件 ×2.8；复鸣铃额外触发一次 |
| 藏锋匣 · 留牌 | 最终候选中的幺九，前9张每次 ×1.22，第10～12张每次 ×2；余音扇重复同张同档 |
| 长春梳 · 成长 | 储存200底分起步，每个合法顺子事件 ×1.17，跨关保留；复鸣铃可重复成长 |

底分含数牌每张10、字牌每张15、合法和牌奖励100及奇物收益。温玉加80整手底分，刻石每刻子事件加60。成长只在合法终局写入一次；预览、动画、跳过和重播均不推进成长。倍率保留6位小数，最终 `floor(底分×倍率)`。末关倍率×0.8。

两模式六关累计门槛均为 **200／500／1,000／2,500／5,500／12,000**，四路线共用。过程分已即时加入累计，不重复乘入和牌分。每关4墨；铜钱仅保留现有聚宝钱等计分用途。

```text
终局累计 = 终局前累计（已含过程分）＋和牌分－诈胡罚分
过关条件 = 终局累计 >= 本关累计门槛
```

V5规则标识 `opening-build-v5`、计分标识 `four-core-v5`，存档 `jade-run-v5`。V1～V4原存档保留，不能在新规则下续局，不静默迁移。改牌保留实体ID和136张原始牌守恒；有效牌面可以超过四张。

## 结算与验证

正式结算已使用 V4 实时主题库和5.4秒构筑爆发演出，展示逐步底分、倍率及冻结留牌。不同高番主题、高分和高倍率独立分档，诈胡使用中性扣分演出。支持跳过、2×、减弱动画、静音及重播；装饰加载超过8秒直接显示权威结果，不卡住继续流程。运行素材约15.95MB，仅加载当前主题，不播放预渲染视频。

验收遵循 [AGENTS.md](AGENTS.md)：浏览器实际试玩为主，自动化只补已有P0文件。数值模型与实际浏览器数据分别记录，定牌样例不能推导胡率。模型首关合法率约39%，有限在线策略不是人类玩家，不能将通关率近似误报为四路期望完全相等。

```sh
npm test
npm run build
```

复用 `tests/browser-harness.html` 提供固定种子正常新局和明确标注的定牌P0场景，不随游戏发布。`scripts/balance-check.mjs` 是V2历史脚本，不适用于当前规则；V5分析源码和复算说明归档在 [v5-balance-data.json](docs/v5-balance-data.json) 内，不增加正式自动化入口。旧版本浏览器记录见 [V4_BROWSER_VALIDATION.md](docs/V4_BROWSER_VALIDATION.md)。

## 文件与素材

当前规则以上文及 [V5数值报告](docs/V5_BALANCE_REPORT.md) 为准；[自由出牌与结算计划](docs/FREE_PLAY_AND_SETTLEMENT_PLAN.md)保留历史讨论。数据采集与统计由独立适配层维护，接口、部署边界和实际交付范围见 [采集接入说明](docs/ANALYTICS_IMPLEMENTATION.md)；纯静态预览不代表服务端已接入。

- `dist/balance.js`：四路线、获取节奏及关卡参数的唯一来源。
- `dist/engine.js`：状态迁移、番型计分、奇物、关卡与不可变结算快照。
- `dist/hand-rules.js`：完整拆解、花色万能解释和保留现牌的补牌可达性检查。
- `dist/riichi-patterns.js`、`dist/mcr-patterns.js`：双模式番型目录、判定与复合规则。
- `dist/pattern-catalog.js`、`dist/pattern-guide.js`：包含奇物解锁及不适用原因的游戏内图鉴。
- `dist/app.js`：游戏页面、交互与浏览器存档。
- `dist/build-hints.js`：只读的成型区／候选留牌进度与真实结算联动提示，不另行计分。
- `dist/settlement-adapter.js`、`dist/settlement/`：冻结结果到演出数据的适配、播放器和音效。
- `dist/tiles.js`、`dist/art/tiles/`：34 种本地 SVG 麻将牌面。
- `dist/style.css`：桌面与手机布局。
- `dist/art/manifest.json`：奇物和背景图片索引，缺失素材保留可玩占位。
- `scripts/balance-check.mjs`：可复现的 V2 试玩模拟。

V2 扩展的奇物固定 ID 为 `single_seal / kong_cauldron / rank_brush / suit_ribbon / wild_jade`；V5另增四核心、复鸣铃、余音扇、补缺符，复用已有插画；三件旧换牌收益奇物停投。`single_chain` 连星珠仅作美术储备，本版本未投放。

运行素材使用 WebP，原始制作文件在上级 `art/` 中保留。麻将图案改编自 [FluffyStuff 的 CC0 麻将矢量素材](https://github.com/FluffyStuff/riichi-mahjong-tiles)，调整配色并绘制蓝框白板，授权记录见 `dist/art/tiles/LICENSE.md`。无需下载麻将字体。
