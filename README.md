# 叠雀 Web 原型 · V6

单人麻将肉鸽。当前开放国标玩法，自由出牌构成完整麻将手牌，用奇物、改牌和换牌提高得分，累计分达到六关逐步提高的门槛。

V6 按已确认方案提供开局核心＋升降笔、每关一次可跨准备／组牌使用的改牌、十倍底分与新四路线档位、累计六关门槛。数值来源见 [V6 方案与独立模拟](docs/V6_BALANCE_PROPOSAL.md)，实现与浏览器验收见 [V6 Review](docs/V6_BROWSER_VALIDATION.md)。模拟通过率不代表真人胜率；四路线收益分布仍有差异。

## 本地运行

完整数据服务需要 Node.js 22.13+，游戏使用原生 JavaScript，服务端为 Worker + D1。

```sh
npm install
npm run dev
```

游戏地址：`http://127.0.0.1:4175/`，统计页：`http://127.0.0.1:4175/analytics/`。启动命令会构建并应用尚未执行的本地数据库迁移；本地数据保存在 `.wrangler/state/`，与线上数据库隔离。

只预览玩法可使用 Python 3：

```sh
npm start
```

打开 `http://127.0.0.1:4173/`。纯静态入口不含采集数据接口。游戏进度保存在当前浏览器；停止预览按 Ctrl+C。

## 部署

项目使用 Vite、Cloudflare Workers 和 D1。Node.js 需为 22.13 或更新版本。部署前安装依赖并登录 Cloudflare：

```sh
npm install
npx wrangler login
npx wrangler d1 create jade-run
```

从 `d1 create` 的结果复制数据库 ID，然后设置 `CLOUDFLARE_D1_DATABASE_ID` 并运行部署命令：

```sh
CLOUDFLARE_D1_DATABASE_ID=<你的数据库 ID> npm run deploy
```

部署脚本会构建 Worker 和静态资源、应用 `drizzle/` 中的远程迁移，再发布 Worker。游戏和 `/analytics/` 共用同一域名；匿名统计由 D1 保存。数据库 ID 只需在本地 shell 或部署环境变量中设置，不要提交到仓库。只需托管纯静态文件时，`dist/` 可交给任意静态文件服务器，但采集接口和统计页需要 Worker 才能工作。

## V6 当前规则

- 仅开放国标入口；日麻旧存档保留。番型图鉴仍列出基础支持、奇物解锁和本作不适用的项目。不凭空判定门清／暗刻／听牌／自摸历史，不要求八番起和。
- 136 张牌墙，12 张候选；准备阶段最多 5 次、每次换 1～5 张。点击开始组牌后停止普通弃换，出几张补几张，其余候选保留。
- 四个核心任选一件，自带升降笔，共占 2 槽。最多 4 槽且仅 1 核心，每关通过后三选一，满槽换辅助或跳过；持续领取的装备曲线为 2／3／4／4／4／4。核心固定，关间不额外买奇物。
- 每关 2 墨。升降、换色、万能和补缺编辑都耗 2 墨，准备与组牌共用，最多改 1 张 1 次；可修改候选或成型区非杠数牌。满 14 个结构位置但尚未结算时也能用普通工具修复。改点限 ±1 且不循环；换色保留点数；万能保留点数，只代万／筒／索。需要持有对应工具。
- 大番核心＋补缺符在组牌未满 14 时另有一次补缺操作：弃换最多 3 张，或使用共用的 2 墨改点／换色，两种操作二选一。补缺弃换不耗墨；没有额外免费编辑。
- 成型区按花色与点数排序，不能取回、替换或换位。单张、多张均可放入；四张相同牌可声明杠，计 3 个结构位置且锁定牌面。最终完整手为 14＋杠数张实体牌。
- 首关奖励包含路线关键件：大番补缺符、刻子／成长复鸣铃、留牌余音扇；之后包含至少一件兼容项。玩家每次只能选一件。停投墨泉、借东风、千层塔、留白扇；非大番不出补缺符，非留牌不出余音扇。
- 风险出牌仍允许确认后打出，不把暂时未成牌误称为无解。最终计算有效奇物与万能解释后仍不合法则为“诈胡”，扣本关累计门槛的 10%（向上取整）。扣后累计仍达标也通过，每关只结算一次。

## 四条计分路线

所有加底分项与单张过程分相对 V5 ×10。数牌每张 100、字牌 150、完整和牌 1,000、温玉 800、刻石每刻／杠事件 600。倍率精度和最终取整规则保持一致：`floor(底分×倍率)`，末关倍率再 ×0.8。

| 核心 | 规则 |
| --- | --- |
| 天机算筹 · 大番 | 番数下限 0／1／2／4／8／16／24／32／48／64／88 对应倍率 1／2／4／12／32／96／256／512／1024／2048／4096，88 番以上线性延伸 |
| 叠岳印 · 刻子 | 每个刻／杠事件 ×2.8；复鸣铃额外触发一次，同时重触发刻石底分，不重复发钱 |
| 藏锋匣 · 留牌 | 最终候选中的幺九，前 9 张每次 ×1.26，第 10～12 张每次 ×2；余音扇重复同张同档 |
| 长春梳 · 成长 | 初始有效底分 2,000，每次合法顺子事件 ×1.17；复鸣可重复成长，跨关保留 |

非大番路线使用普通国标倍率 `1＋番/8`，再叠自身奇物。成长内部仍储存 200 起步，结算时取整再 ×10，不能在存储和展示重复乘十。预览、动画、跳过与重播不推进成长，不重复结算。单张过程分不乘最终倍率。

六关累计门槛为 **1,000／5,000／12,000／30,000／80,000／180,000**，四路线共用。铜钱保留聚宝钱等用途。

```text
终局累计 = 终局前累计（已含过程分）＋和牌分－诈胡罚分
过关条件 = 终局累计 >= 本关累计门槛
```

V6 规则标识 `opening-build-v6`、计分标识 `four-core-v6`，存档 `jade-run-v6`。旧版原存档保留，不能在新规则下续局，不静默转换旧墨额度。改牌保留实体 ID 和 136 张原始牌守恒；有效牌面可以超过四张。

## 结算与验证

正式结算已使用 V4 实时主题库和5.4秒构筑爆发演出，展示逐步底分、倍率及冻结留牌。不同高番主题、高分和高倍率独立分档，诈胡使用中性扣分演出。支持跳过、2×、减弱动画、静音及重播；装饰加载超过8秒直接显示权威结果，不卡住继续流程。运行素材约15.95MB，仅加载当前主题，不播放预渲染视频。

验收遵循 [AGENTS.md](AGENTS.md)：浏览器实际试玩为主，自动化只补已有P0文件。数值模型与实际浏览器数据分别记录，定牌样例不能推导胡率。V6 独立模型每路线 2,000 局，首关合法率约 75%、六关通过率约 44%～57%；有限策略不是人类玩家，也没有覆盖普通策略的杠与万能操作。不能把该结果称为四路完全平衡。

```sh
npm test
npm run build
```

复用 `tests/browser-harness.html` 提供固定种子正常新局和明确标注的定牌P0场景，不随游戏发布。`scripts/balance-check.mjs` 是V2历史脚本，不适用于当前规则；V6 复算说明归档在 [V6 方案](docs/V6_BALANCE_PROPOSAL.md)，结果在 [v6-balance-proposal-data.json](docs/v6-balance-proposal-data.json) 内，不增加正式自动化入口。旧版本浏览器记录见 [V4_BROWSER_VALIDATION.md](docs/V4_BROWSER_VALIDATION.md)。

## 文件与素材

当前规则以上文及 [V6方案](docs/V6_BALANCE_PROPOSAL.md) 为准；[自由出牌与结算计划](docs/FREE_PLAY_AND_SETTLEMENT_PLAN.md)保留历史讨论。数据采集与统计由独立适配层维护，接口、部署边界和实际交付范围见 [采集接入说明](docs/ANALYTICS_IMPLEMENTATION.md)；纯静态预览不代表服务端已接入。

- `dist/balance.js`：四路线、获取节奏及关卡参数的唯一来源。
- `dist/engine.js`：状态迁移、番型计分、奇物、关卡与不可变结算快照。
- `dist/hand-rules.js`：完整拆解、花色万能解释和保留现牌的补牌可达性检查。
- `dist/riichi-patterns.js`、`dist/mcr-patterns.js`：双模式番型目录、判定与复合规则。
- `dist/pattern-catalog.js`、`dist/pattern-guide.js`：包含奇物解锁及不适用原因的游戏内图鉴。
- `dist/app.js`：游戏页面、交互与浏览器存档。
- `dist/build-hints.js`：只读的成型区／候选留牌进度与真实结算联动提示，不另行计分。
- `dist/settlement-adapter.js`、`dist/settlement/`：冻结结果到演出数据的适配、播放器和音效。
- `dist/tiles.js`、`dist/art/tiles/`：34 种本地 SVG 麻将牌面。
- `dist/style.css`：桌面与手机布局。
- `dist/art/manifest.json`：奇物和背景图片索引，缺失素材保留可玩占位。
- `scripts/balance-check.mjs`：可复现的 V2 试玩模拟。

V2 扩展的奇物固定 ID 为 `single_seal / kong_cauldron / rank_brush / suit_ribbon / wild_jade`；V5另增四核心、复鸣铃、余音扇、补缺符，复用已有插画；V6 另停投墨泉，旧换牌收益奇物继续停投。`single_chain` 连星珠仅作美术储备，本版本未投放。

运行素材使用 WebP，原始制作文件在上级 `art/` 中保留。麻将图案改编自 [FluffyStuff 的 CC0 麻将矢量素材](https://github.com/FluffyStuff/riichi-mahjong-tiles)，调整配色并绘制蓝框白板，授权记录见 `dist/art/tiles/LICENSE.md`。无需下载麻将字体。
